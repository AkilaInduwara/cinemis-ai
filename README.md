# React + Vite


I’m excited to share a glimpse of my final-year individual project for my BSc (Hons) in Software Engineering: CineMIS AI, a movie and TV show identification system. 🎬

Have you ever tried to recall a movie or TV show but could only remember a few scenes, lines, or a vague plot? CineMIS AI solves exactly that.

Users can:

🔍 Search by the exact title to find detailed information about any movie or TV show.

🧠 Identify movies or TV series by entering a plot description they remember.

🎧 Even upload a short video or audio clip to discover the title automatically!

It’s built with React (frontend) and FastAPI + Python (backend), powered by curated movie and subtitle datasets for accurate identification.
